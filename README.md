# 电控第二次培训任务——自定义串口通信协议

1. 功能简介
本项目基于 STM32G473RBT6 实现以下功能：
- LED 以可调频率闪烁（1Hz / 2Hz / 3Hz）
- 舵机在可调幅度内来回摆动（小 / 中 / 大）
- 通过串口接收上位机指令，实时修改以上参数
- 可通过按键执行相同操作（单击改频率，双击改幅度，长按开关）
- 支持串口状态查询，回传当前系统状态

## 2. 通信协议格式
串口通信采用 **自定义帧格式**，波特率 `115200`，8 位数据位，无校验，1 位停止位。

### 2.1 基本帧结构（4 字节）
| 字节位置 | 名称 | 说明 |
|---------|------|------|
| Byte 0 | 帧头 | 固定 `0xAA` |
| Byte 1 | 指令码 | 见下方指令表 |
| Byte 2 | 数据 | 指令参数 |
| Byte 3 | 帧尾 | 固定 `0x55` |

### 2.2 特殊帧结构（5 字节）
当指令码为 `0x04`（直接设置舵机角度）时，数据需要 2 个字节：
| Byte 0 | Byte 1 | Byte 2 | Byte 3 | Byte 4 |
|--------|--------|--------|--------|--------|
| 0xAA | 0x04 | 角度高字节 | 角度低字节 | 0x55 |

角度范围为 `500 ~ 2500`（单位：微秒），例如 `2500us` 对应 `0x09 0xC4`。

## 3. 指令表
| 指令码 | 功能 | 数据含义 | 示例（十六进制） |
|--------|------|----------|------------------|
| 0x01 | 系统开关 | 0=关闭，1=开启 | `AA 01 01 55` |
| 0x02 | 设置闪烁频率 | 1=1Hz，2=2Hz，3=3Hz | `AA 02 03 55` |
| 0x03 | 设置摆动幅度 | 0=小，1=中，2=大 | `AA 03 02 55` |
| 0x04 | 直接设置舵机角度 | 高字节+低字节（500~2500） | `AA 04 09 C4 55` |
| 0x05 | 查询当前状态 | 固定 0 | `AA 05 00 55` |

### 状态回传格式（单片机 → 上位机）
当收到 `0x05` 指令后，单片机通过串口发送 5 字节：
| Byte 0 | Byte 1 | Byte 2 | Byte 3 | Byte 4 |
|--------|--------|--------|--------|--------|
| 0xAA | 开关状态 | 频率档位 | 幅度档位 | 0x55 |

例如：`AA 01 02 00 55` 表示系统开启、频率 2Hz、幅度小。

## 4. 使用说明
1. 使用 USB 转 TTL 模块（或 DAP-Link 的串口功能）连接单片机，注意 **RX-TX 交叉连接**。
2. 打开串口助手（如 XCOM），选择对应串口，波特率 `115200`，勾选“十六进制发送”。
3. 按上表发送指令，即可实时控制 LED 与舵机。
4. 发送 `AA 05 00 55` 可查询当前状态，串口助手会收到 5 字节回传。

## 5. 工程结构
```
2ND_1/
├── Bsp/          # 板级支持包：led、servo、key、uart、tim
├── Drv/          # 驱动层：按键状态机、串口协议解析
├── Task/         # 任务层：控制逻辑（LED闪烁、舵机摆动、指令响应）
├── Core/         # CubeMX 生成的初始化代码及 main.c
└── CMakeLists.txt
```

## 6. 注意事项
- 串口接收使用 **DMA + IDLE 空闲中断**，DMA 模式为 **Circular**，确保不定长数据可靠接收。
- 所有业务代码均已分层，便于维护和扩展。
- 若使用按键操作，功能与串口指令一致（单击改频率、双击改幅度、长按开关）。
